# OmniFilter

Change automatiquement le filtre ReShade selon la map de Dead by Daylight.

Quand tu appuies sur TAB, Échap, ou Start / Back à la manette, OmniFilter lit le nom de la map en bas de l'écran et active le filtre qui correspond. À l'écran des scores, il remet le filtre Stream. Le logiciel ne touche pas au jeu : il lit l'écran et simule des raccourcis clavier ReShade.

## Il te faut

- Windows 10 ou 11
- Dead by Daylight en français
- ReShade installé dans le jeu
- Le pack « steaxs filters » copié dans le dossier du jeu (il n'est pas fourni ici)

## Installation

1. Télécharge `OmniFilter.exe` dans la page [Releases](https://github.com/Exprimes/OmniFilter/releases/latest).
2. Ferme le jeu, puis lance `OmniFilter.exe`. Il ajoute les raccourcis dans `ReShade.ini` et garde une sauvegarde (`ReShade.ini.bak`).
3. Lance le jeu en fenêtré sans bordure et appuie sur TAB en partie.

Si Windows affiche « Windows a protégé votre ordinateur », clique sur « Informations complémentaires », puis « Exécuter quand même » : le logiciel n'est pas signé.

OmniFilter vérifie les mises à jour à chaque lancement et te demande avant d'installer une nouvelle version.

## À savoir

Vérifie les règles actuelles de Dead by Daylight sur ReShade avant de l'utiliser.
